# CIFAR10-Small-Data-Robustness
# Robust CIFAR-10 Classification from 500 Training Images

## Files

- `CIFAR10_Small_Data_Robustness.ipynb`: all code (Parts A to F)
- `Section_B_Q1_Summary.docx`: one-page summary, generated by the last notebook cell

## Run on Google Colab

1. Open https://colab.research.google.com and choose File > Upload notebook.
2. Select `CIFAR10_Small_Data_Robustness.ipynb`.
3. Choose Runtime > Change runtime type > T4 GPU > Save.
4. Choose Runtime > Run all.
5. Wait for all cells to finish (about 20 to 35 minutes). CIFAR-10 downloads automatically.
6. The last cell creates `Section_B_Q1_Summary.docx` and downloads it.

## Run locally

1. Install Python 3.10 or newer.
2. Install the dependencies:

    pip install torch torchvision numpy pandas matplotlib jupyter python-docx

3. Start Jupyter and open the notebook:

    jupyter notebook CIFAR10_Small_Data_Robustness.ipynb

4. Choose Kernel > Restart & Run All. A GPU is recommended; on CPU the run takes several hours.

## Notes

- CIFAR-10 is downloaded to `./data` on the first run.
- Do not interrupt the run midway; training is not checkpointed. If it stops, run all cells again from the top.
- The hidden corruption is defined in the function `hidden_corruption()`. Edit it there if your assignment specifies a different one, then run all cells again.
